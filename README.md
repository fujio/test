## 天気予報サイト

### 香川県天気予報サイト

`weather.html` - 香川県の天気を1時間ごとに予測するシンプルなWebサイト

#### 機能
- 香川県（高松）、高松市、綾川町の3地域の天気予報
- 1時間ごとの詳細な予報（最大24時間）
- 気温、天気、降水確率の表示
- リアルタイム更新機能
- レスポンシブデザイン

### 大阪府天気予報サイト

`osaka-weather.html` - 大阪府の天気を1時間ごとに予測するシンプルなWebサイト

#### 機能
- 高槻市、吹田市の2地域の天気予報
- 1時間ごとの詳細な予報（最大24時間）
- 気温、天気、降水確率、風速の表示
- リアルタイム更新機能
- レスポンシブデザイン

### 使い方
ブラウザで各HTMLファイルを開くだけで使用できます。APIキーは不要です（Open-Meteo APIを使用）。
